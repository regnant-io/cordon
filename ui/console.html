Authorizing an admin command

          
Admin routes require an Ed25519 signature over
            CORDON_ADMIN:{action}:{params} under the CMK-derived
            admin key. Produce one with
            cordon-keygen admin-sign. With no CMK provisioned the
            admin API is refused outright.
