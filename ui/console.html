              Reference
              
API reference

              
Every route this node serves, and what authorises it. client
                means a certificate the node has enrolled; K_admin means an Ed25519
                signature under the CMK-derived admin key.

            

            

              

                
                
              

            

          


          


            

              
Health

              

                
RouteAuthPurpose

                
GET /v1/health
                    none
                    Liveness. Reveals only that a node is listening.

                
GET /v1/health/detailed
                    client
                    Full posture: measurements, key provenance, audit state.

                
GET /v1/health/runtime
                    client
                    Recent model-runtime output, for diagnosing startup failures.

              

            


            

              
Inference

              

                
RouteAuthPurpose

                
POST /v1/inference
                    client
                    Generate. Returns an Ed25519-signed response over a canonical, reconstructable payload.

                
POST /v1/inference/stream
                    client
                    Generate over SSE. Filtered incrementally with a trailing holdback, so nothing the policy would remove is ever transmitted. Refused while timing normalisation is enabled.

                
GET /v1/models
                    client
                    Registered bundles and their integrity state.

                
POST /v1/models
                    K_admin
                    Register a bundle already present in the model store.

              

            


            

              
Assurance

              

                
RouteAuthPurpose

                
GET /v1/attestation
                    client
                    A signed measurement report, bound to a nonce the caller chose.

                
POST /v1/attestation/verify
                    client
                    Check a report against operator-pinned measurements. The caller supplies only a nonce.

                
GET /v1/audit/verify
                    client
                    Recompute and check the whole chain.

                
GET /v1/audit/tail
                    client
                    The most recent entries. The read is itself recorded.

                
GET /v1/audit/anchor
                    client
                    Signed chain head. Publish it to make earlier rewrites detectable.

              

            


            

              
Administration

              

                
RouteAuthPurpose

                
POST /v1/admin/quarantine
                    K_admin
                    Stop serving until an operator recovers.

                
POST /v1/admin/recover
                    K_admin
                    Resume serving. Refused while any bundle fails integrity.

                
POST /v1/admin/suspend-client
                    K_admin
                    Suspend one client for a period.

                
POST /v1/admin/teardown
                    K_admin
                    Zeroize key material and stop. There is no undo.

                
GET /metrics
                    loopback
                    Prometheus exposition. Refused from any non-local peer.

              

            


            

              
Authorising an admin command

              

                
Admin routes require an Ed25519 signature over
                  CORDON_ADMIN:{action}:{params} under the CMK-derived admin key.
                  Produce one with cordon-keygen admin-sign. With no Client Master Key
                  provisioned, the admin API is refused outright rather than falling back to a weaker check.
