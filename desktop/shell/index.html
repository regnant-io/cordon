On this computer

Download

Checked against the digest the publisher released. Downloads resume if interrupted.

Sealed bundles

A sealed bundle is a model encrypted under your key: AES-256-GCM, one derived key per shard. The node decrypts it only to load it, and nothing without the key can read it.

Keys

Your Client Master Key seals bundles and, outside Light mode, signs the audit log and every response. Everything Cordon derives comes from it.

Deployment mode

What the node claims about itself. Each mode past Light rests on hardware and keys it checks at start, and refuses to run if they are missing.

Remote access

Let other machines use this node. Exposure is always mutual TLS: every caller needs a certificate you issued here, and you can revoke it.
